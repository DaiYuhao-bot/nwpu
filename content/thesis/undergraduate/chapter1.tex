\section{研究背景与意义}

近年来，复杂环境下的自主机器人技术快速发展，移动机器人与协作机械臂等智能体常需在高动态、非结构化等复杂工况下执行任务。面对未知且高风险的真实物理环境，依靠真实世界进行智能体感知、决策与控制算法的训练不仅成本极为高昂，且存在巨大的系统损毁风险。因此，构建高保真的虚拟仿真场景进行算法的验证与部署前评估，是重要途径之一。然而，传统的物理仿真环境通常依赖繁琐的人工建模，在复杂场景生成效率、物理参数映射的细粒度以及场景的视觉-物理时空一致性上存在显著不足，导致虚拟环境与真实环境差异较大，难以满足泛化智能体高效、高精度的 Sim2Real（仿真到现实）迁移需求。

以神经辐射场（NeRF）\cite{nerf}和三维高斯溅射（3DGS）\cite{3dgs}为代表的三维表征技术突破后，基于单图、多视角或文本序列的高效场景外观生成快速发展。但这些方法多侧重于静态几何与光学外观，缺乏内在的质量、弹性、密度等力学属性，无法在仿真场景中产生符合真实物理规律的动态交互。部分前沿研究尝试将物质点法（MPM）等连续介质力学模拟\cite{mpm}融合进基于 3DGS 等散点的表达中\cite{physgaussian}，但大多局限于单一材质或无复杂背景干扰的简单物体。当面对包含遮挡关系、复杂结构等多材质耦合的环境时，由于缺乏面对场景的材质识别机制，往往面临人工材质分割效率低、场景多样性不足等问题；此外，场景级的数据在连续体仿真中大规模的背景网格会牵连整个网格系统，易导致网格刚体化和梯度计算发散等瓶颈。

针对现有复杂场景仿真中物理真实性不足与生成效率低下等痛点，本文以搭建视觉场景生成与复杂物理动力学演化之间的桥梁为核心目标，探索并构建了物理知识嵌入的复杂场景生成与仿真系统。系统通过集成视觉分割大模型（SAM）\cite{sam}、视觉语言模型（VLM）与 Feature Splatting\cite{featuresplatting} 语义-物理统一表征框架，在三维空间中自动化地完成材质属性分布与本构模型的识别，从而构建适用于复杂非结构化环境的高保真虚拟场景。

在理论与算法层面，本文实现了"材质理解——三维映射——多材质仿真"的技术链路：通过 VLM 自动材质识别与经验映射替代手工指定物理参数，并通过前景—背景解耦仿真架构隔离大规模静态背景的干扰，为多材质复杂场景的物理仿真提供可自动化的初始化与求解范式。此外，利用视频扩散模型蒸馏优化物理参数，进一步提高了场景材质的准确性与虚拟环境仿真的保真度。在工程层面，本文构建的生成式仿真流程为复杂场景下的视觉-物理联合建模提供了端到端的实现参考，模块化的管线设计为后续扩展至更丰富的交互场景预留了接入空间。

\section{国内外研究现状}

针对"物理知识嵌入的复杂场景生成与仿真"这一交叉领域，本节从三维表征与生成、场景分割与语义理解及物理知识嵌入三个层面梳理相关进展。

\subsection{三维场景表征与生成}
NeRF\cite{nerf} 以多层感知机将连续空间坐标与视角方向映射为体密度与辐射度，借助可微分体积渲染和稀疏视角光度损失进行训练，开创了隐式神经场景表征与高质量新视角合成的新范式。Kerbl 等人随后提出的三维高斯溅射（3DGS）\cite{3dgs} 以百万级各向异性高斯椭球体显式表征场景的几何与外观，借助基于图块的可微光栅化与自适应密度控制，在保持重建质量的同时实现了实时渲染，突破了隐式表征沿射线逐点查询的速率瓶颈。Deformable 3D Gaussians\cite{deformable3dgs} 在规范空间中定义静态高斯集合并引入可学习形变场，为各高斯预测时序位置偏移与协方差变换，将高斯表征从静态空间扩展至动态场景。在三维场景生成方面，DreamFusion\cite{dreamfusion} 提出分数蒸馏采样（SDS），以冻结的 2D 扩散模型为可微评分器，将文本到三维的生成转化为随机视角参数优化问题；LucidDreamer\cite{luciddreamer} 沿相机轨迹借助 2D 扩散修复模型逐帧补全未观测区域，经深度估计将 2D 补全结果对齐提升为三维高斯散点，以增量拼接实现从单物体到完整场景的渐进式扩展；Director3D\cite{director3d} 引入相机姿态编码器与 SDS 联合优化，通过显式建模多视角间的几何关联来缓解随机视角采样引发的多面一致性退化；FlashWorld\cite{flashworld} 以图像到三维高斯的前馈式重建替代逐场景迭代优化，将场景构建耗时压缩至秒级。上述方法聚焦于视觉外观的高保真呈现——所得虚拟实体仅具备光影与几何包络，缺乏质量、弹性等力学本构属性，无法支撑需要物理碰撞与动态响应的交互。这是本文试图从物理知识嵌入角度加以弥补的核心问题。

\subsection{二维与三维场景分割}
精确的场景分割是连接视觉感知与物理属性标注的桥梁，其任务是在二维图像或三维空间中将场景解构为语义独立的区域。在二维层面，Segment Anything Model（SAM）\cite{sam} 基于 Transformer 视觉编码器、提示编码器与轻量掩码解码器架构，实现了点、框、掩码等多模态输入驱动的零样本分割；其后续版本 SAM 2\cite{sam2} 引入流式记忆库与时序注意力机制，将分割能力从单帧图像扩展至视频帧间的目标持续追踪；MobileSAM\cite{mobilesam} 则通过解耦式知识蒸馏将 Teacher 模型能力压缩至消费级硬件可实时运行的规模。在三维层面，SegAnyGaussian\cite{seganygaussian}（SAGA）为每个 3D 高斯附加可学习的尺度门控亲和力特征，通过将高斯渲染的二维掩码投影与 SAM 输出进行对比学习，实现了三维空间内的提示式实例分割。然而，此类方法解决的是"物体在哪里"的定位问题，无法回答"物体是什么材质、有何物理属性"。从视觉分割到语义认知的跨越，需借助视觉语言大模型的感知推理能力。

\subsection{三维语义理解与特征蒸馏}
在场景分割提供空间解构的基础上，三维语义理解旨在赋予每一语义区域以语言级语义标签乃至物理属性。LERF\cite{lerf} 在 NeRF 中联合训练密度、颜色与 CLIP 特征场，通过特征金字塔多尺度渲染与 DINO 空间正则化，使场景中任意三维位置均可响应自然语言查询，其整体流程如图~\ref{fig:lerf}~所示；LangSplat\cite{langsplat} 在此基础上将范式迁移至 3DGS 显式表征，利用 SAM 为高斯分配实例级语义掩码，经三平面哈希编码器压缩 CLIP 高维特征后构建三维语言场，以更优的渲染效率实现了零样本三维语义检索。Feature Splatting\cite{featuresplatting} 进一步将 CLIP 与 DINOv2\cite{dinov2}特征联合蒸馏至三维高斯，通过文本查询实现场景部件的半自动分解，并基于 MPM 仿真器的预设材质模板驱动动态模拟，确立了语义蒸馏与物理仿真的衔接范式。Feature Splatting 虽衔接到物理仿真，其力学参数仍依赖人工预设模板，未建立从视觉语义到连续物理参数的自动映射。本文引入视觉语言大模型进行逐实例材质推理与物理参数范围估计，并通过 SVD\cite{svd} 视频扩散先验对初始参数进行梯度寻优。

\subsection{物理知识嵌入三维场景的技术路线}
物理知识嵌入指将材料本构关系、力学属性及物理定律系统性地融入纯视觉三维表征，使场景不仅具备静态几何外观，更能在外部激励下遵循真实物理规律产生形变、碰撞等动态交互。围绕这一目标，形成了三条在自动化程度与物理保真度之间各有权衡的技术路线。

\textbf{数据驱动的物理属性推理与赋值：}该路线直接利用视觉语言大模型的先验知识，从二维视觉信号中推理场景各部件的材质类别与物理参数——杨氏模量 $E$、泊松比 $\nu$ 和密度 $\rho$——，再将推理结果显式赋值至三维表征的对应区域。以 GaussianProperty\cite{gaussianproperty} 为代表，该方法从 3D 高斯场景渲染多视角图像，由 VLM 逐视图推断材质标签与物理属性，经多视角投票与一致性融合将二维推理结果投影回三维高斯原语空间，实现了从视觉表观到力学参数的自动化映射。该路线的瓶颈在于推理精度受限于 VLM 的视觉理解能力——对于视觉特征模糊、跨材质外观相似的区域，单一 VLM 推断难以给出可靠且细粒度的物理参数分布，且多视角推理中的视图间歧义可能导致参数赋值不一致。

\textbf{连续介质力学与三维表征的耦合：}该路线将物质点法（MPM）、有限元法（FEM）等连续介质力学求解器与 NeRF、3DGS 等视觉表征深度耦合，在物理保真度方面表现最优。PhyRecon\cite{phyrecon} 首次在统一框架内耦合隐式曲面可微渲染与 FEM 力学仿真——前者提供多视角光度监督以恢复几何外观，后者通过求解弹性动力学方程约束几何在受力条件下的变形行为，二者经端到端联合训练输出物理可解释的隐式表面。PhysGaussian\cite{physgaussian} 提出将 3DGS 的各向异性高斯椭球体直接复用为 MPM 物质点：以高斯均值位置为粒子初始位置，由协方差矩阵推导局部体积与初始形变梯度，将高斯溅射表示无缝转换为连续介质质点的集合，无需额外空间离散化即可驱动仿真。PhysGen3D\cite{physgen3d} 在此基础上探索了单图到可交互场景的生成路径——通过扩散模型补全不可见区域后构建 3DGS 场景，引入刚体绑定与运动重定向策略赋予动态交互能力。该类路线遵循质量、动量、能量守恒定律与弹塑性本构方程，仿真结果具备物理可解释性；但在复杂多材质、大规模背景场景中面临网格刚体化与梯度发散等稳定性瓶颈。

\textbf{视频生成模型作为隐式物理先验：}与上述两条显式赋予物理属性的路线不同，该路线利用大规模视频生成模型内部蕴含的"物理常识"作为隐式监督信号。DreamPhysics\cite{dreamphysics} 以 SVD\cite{svd} 作为物理评分器：将 MPM 仿真渲染帧与 SVD 预期运动帧的分布偏差通过 SDS 转化为弹性模量 $E$ 的优化梯度，经 Warp\cite{warp} 全可微 MPM 管线反传至每一物质点，实现逐粒子物理参数的自监督纠偏。PhysDreamer\cite{physdreamer} 探索了视频扩散先验对宏观动力学参数的联合推断——通过为静态 3D 资产合成多视角交互视频并反推质量、弹性系数与阻尼等参数，驱动其产生符合物理常识的动态运动。该路线的优势在于无需真值物理参数标注即可实现自监督优化；但扩散模型的物理合理性受限于训练数据中慢动作镜头、非物理特效等运动偏差，且 SDS 梯度的高方差特性导致优化收敛缓慢。

本文系统整合了上述路线，贯通从文本到可仿真虚拟场景的全自动流程：以 VLM 数据驱动推理提供材质先验，以连续介质力学 MPM 为物理仿真底座，以视频扩散先验优化多材质物理参数。

面向物理仿真的三维场景构建与材质初始化。以文本或参考图像作为输入，引入 FlashWorld\cite{flashworld} 零样本生成多视角图像与相机位姿，构建三维高斯场景雏形。针对复杂场景中的遮挡混叠问题，采用 Depth-Anything-V2\cite{depthanythingv2} 估计单目深度，并以 SAM\cite{sam} 自动分割产生的语义块为基础进行 K-Means\cite{kmeans} 深度聚类分层，将前景物体与背景在空间上解耦至独立的深度层，获取按层隔离的物体掩码区域；进而调用视觉语言模型对每个孤立区域进行材质推理与分类，最终将材质语义映射为杨氏模量、泊松比与密度的初始物理属性范围，为后续物理参数优化提供约束先验。

基于 Feature Splatting\cite{featuresplatting} 框架的语义特征蒸馏与前景背景分离。该模块承担两大任务：其一是，提取二维图像中的 CLIP\cite{clip} 与 DINO\cite{dino} 视觉特征，通过可微 $\alpha$-blending 光栅化将对象级/零件级特征联合蒸馏为每个三维高斯的视觉蒸馏特征；二是，将 VLM 推理得到的材质语义标签通过独立语义标签解码器同步蒸馏至高斯空间，约束物理材质分类与视觉蒸馏特征对齐。在此基础上，引入文本驱动的前景分割机制基于文本向量与多步骤分割框架冻结大体积静态背景，并辅以连通分量分析与 SAM 掩码反投影作为补充链路，实现前景主体与静态背景的解耦，避免大规模背景网格牵连导致的计算发散。

多材质 MPM 仿真与视频扩散先验引导的物理参数优化。利用物质点法（MPM）\cite{mpm,physgaussian}对筛选出的前景高斯散点进行多材质连续介质力学仿真。不同语义标签的质点被赋予弹性、粘弹性、塑性等本构模型，以及 $E$、$\nu$、$\rho$ 等初始物理参数。在此基础上，集成 DreamPhysics\cite{dreamphysics} 物理优化模块：以 Stable Video Diffusion（SVD）\cite{svd} 作为隐式物理先验，将 MPM 仿真渲染帧与 SVD 预期运动的分布偏差通过分数蒸馏采样（SDS）转化为弹性模量 $E$ 的优化梯度，经 Warp\cite{warp} 全可微物理管线反传至每一物质点；优化过程中集成了 CFL 自适应时间步长、逐粒子杨氏模量钳位与按材质类型梯度归一化等保障数值稳定性的措施。

\section{论文组织结构}

本文的组织结构安排如下：



第一章：绪论。阐述复杂场景生成与物理仿真的研究背景与意义，梳理三维场景表征与生成、二维与三维场景分割、三维语义理解与特征蒸馏、以及物理知识嵌入三维场景四个方面的国内外研究现状，在此基础上明确本文贯通三维场景生成与物理知识嵌入的核心研究内容。

第二章：相关技术基础。沿着三维场景表征、视觉语义理解、连续介质仿真与视频生成的主线，分别介绍神经辐射场与三维高斯溅射的渲染理论，SAM、CLIP、DINO 与 VLM 等视觉基础模型原理，三维高斯特征蒸馏框架，以及物质点法数值求解流程与视频扩散模型及分数蒸馏采样机制。

第三章：面向物理仿真的三维场景构建与材质初始化。从文本或参考图像出发，以 Director3D 扩散轨迹生成配合 FlashWorld 前馈重建构建三维高斯场景雏形；针对遮挡混叠问题，引入单目深度估计与基于语义块的 K-Means 深度聚类分层实现前景背景空间解耦；在此基础上由 SAM 自动分割提供语义单元，Qwen3-VL 视觉语言大模型逐层进行材质推理，并通过经验映射将材质语义转化为初始物理参数范围。

第四章：基于三维高斯的语义特征蒸馏与前景背景分离。阐述高斯原语上视觉蒸馏特征与材质语义标签的嵌入方式，对象级与零件级 CLIP 特征及 DINOv2 空间结构特征的预提取流程，RGB 重建损失、余弦相似度蒸馏损失、前景-背景对比损失及语义分类损失等共计多项损失函数的联合优化方案，以及面向物理仿真的材质分类体系与五阶段前景分割管线。

第五章：多材质本构建模与视频扩散引导的物理参数优化。论述质点填充与空间离散化方法，涵盖弹性、粘弹性、弹塑性等求解器的多材质本构模型体系，以及语义标签到物理参数的映射流程；在此基础上阐述以 SVD 视频扩散模型为隐式物理先验、通过分数蒸馏采样驱动杨氏模量梯度优化的机制，并分析运行时 CFL 自适应时间步长与逐粒子钳位等数值稳定措施。

第六章：平台实验结果与系统分析。介绍实验的软硬件环境、实验对象与对比方法，以 VBench 五维评测指标和空间-时间切片为评价工具，对不同方法生成的动态视频进行定量对比与定性可视化分析，并对评测局限性加以讨论。

第七章：总结与展望。对全文工作进行总结，归纳核心贡献，并从场景几何与材质感知、仿真稳定性与优化效率、前景分割与交互规模三个维度分析当前局限并提出未来研究方向。
