\chapter{基于三维高斯的语义特征蒸馏与前景背景分离}

\section{引言}
在上一章中，系统基于视觉语言大模型和深度分层技术，完成了二维平面下的细粒度实例掩码提取与基础本构属性映射，并获得了带有空间位姿信息的初始点云。然而，对于后续的三维物理仿真（如物质点法）而言，纯粹的二维掩码和稀疏离散点云并不足以支撑连续、高保真的几何碰撞与材质运算。这就要求我们将从多重视图和二维基础模型中提取到的高维特征，精确且稳定地投影到具有明确几何体积的三维表征之中。
为此，本文系统以三维高斯溅射（3D Gaussian Splatting, 3DGS）\cite{3dgs}为三维表征，基于 Feature Splatting\cite{featuresplatting}的框架采用了联合语言先验与视觉几何先验的特征蒸馏方案，其流程如图~\ref{fig:chapter4}所示。本章依次阐述高斯原语中特征向量的嵌入方式、CLIP 与 DINO 多尺度特征的蒸馏策略、材质分类的特征蒸馏策略及自适应 DINO 损失Warmup机制，最后结合空间梯度边界约束与材质分类框架实现背景剔除与前景材质的分割。

\section{高斯原语的语义扩展}
经典的三维高斯溅射技术凭借其显式的高斯椭球体与可微光栅化渲染管线，在静态场景的新视角合成任务上取得了显著成果。每个高斯原语包含中心位置、协方差矩阵、透明度以及由球谐函数（SH）描述的颜色信息。
为了使高斯原语在表达视觉几何的同时承载力学仿真所需的语义与物质类别，系统为每个高斯球挂载两组独立的高维语义通道：

\textbf{视觉蒸馏特征（Distilled Visual Features）}：存储从 CLIP\cite{clip}与 DINO\cite{dino}视觉基础模型中蒸馏提取的跨模态语义与细粒度几何特征，并进一步扩展为部件级（part-level）视觉蒸馏特征通道，以支持更细粒度的物体分区表征。

\textbf{材质语义标签（Material Semantic Labels）}：存储 VLM（Qwen3-VL-32B）\cite{qwen25vl}对场景各区域推理预测的材质类别标签，经材质语义标签蒸馏后同步映射至三维高斯空间，使每个高斯原语明确归属到具体的材质大类（如刚体、弹性体、织物等）。

在正向渲染过程中，这两组蒸馏通道与传统光栅化的颜色共享同一组 $\alpha$-blending 权重与透射率积分，各自通过独立的轻量级解码器分别输出重建的视觉特征图与材质分类 logits。视觉蒸馏特征以 CLIP/DINO 预提取的多视特征图为监督目标计算余弦相似度损失，材质语义标签以 VLM 材质分类标签为监督目标计算交叉熵损失，两组通道在统一的高斯训练框架下各自收敛至对应的二维监督信号。


\section{二维视觉特征预提取：多层级视觉监督信号生成}

在将特征蒸馏至高斯原语之前，系统需先从原始多视角图像中提取高质量的多层级视觉特征作为监督目标。该预处理阶段由 \nolinkurl{compute_obj_part_feature.py} 模块独立完成，为后续的 Feature-Splatting 训练提供三类互补的视觉特征信号。

\subsection{对象级与零件级 CLIP 特征}
在第三章所述的 YOLO-MobileSAMv2\cite{yolov8,mobilesam}检测-分割管线基础上，特征提取模块进一步将掩码用于语义特征的聚合与增强。CLIP 特征的提取分为两个层次：
\textbf{对象级特征（Object-level Features）}：将整帧图像送入 CLIP ViT-L/14 编码器（输入分辨率 336 像素），获取保留空间布局的 patch-level 特征图（维度 $C \times H_{\text{patch}} \times W_{\text{patch}}$）。随后利用 YOLO-MobileSAMv2 获得的实例掩码对特征图进行空间掩码平均池化，得到每个检测对象的全局语义特征向量。

\textbf{零件级特征（Part-level Features）}：当系统配置为 \texttt{clip\_part} 模式时，对 YOLO 检测出的每个包围盒区域单独裁剪，缩放至统一分辨率后独立编码，获得零件级的局部语义特征；将各包围盒特征按空间位置回贴至图像网格中，形成保留细粒度材质分区的零件级特征图。两种特征经维度级联后统一通过双线性插值降维至蒸馏特征维度（默认 32 维）。

\subsection{DINOv2 空间结构特征}
为了增强对物体边界和局部纹理的感知，系统同步从 DINOv2\cite{dinov2} ViT-S/14 自监督模型中提取 patch token 特征（输入最长边 1024 像素）。DINOv2 通过自蒸馏预训练习得的注意力机制天然对物体轮廓与高频纹理具有响应，其 patch 特征图为后续的语义一致性约束提供空间平滑性引导。

为增强特征提取的鲁棒性，系统在此基础上引入了多项过滤与质量保障机制：（1）\textbf{超大掩码面积过滤}：当 YOLO 检测框或 SAM 分割掩码覆盖超过预设面积比例的图像区域时（默认阈值分别为 0.4 与 0.5），自动丢弃该类大面积伪目标，避免墙壁、桌面等背景区域污染语义特征；（2）\textbf{检测失败安全降级}：当检测器对某帧图像完全失效时，系统不再回退至全图伪目标掩码，而是输出空掩码并依赖后续的背景填充机制以原始全图 patch 特征补全未覆盖区域，从根源上防止背景语义混入前景特征；（3）\textbf{DINOv2 特征逐像素 L2 归一化}：在保存 DINO patch 特征前执行逐通道归一化，消除不同图像间特征尺度的系统性偏移，使后续余弦相似度监督更加稳定。

经此阶段，每帧图像生成三类特征文件共同构成蒸馏训练阶段的多源语义监督信号。

\section{CLIP与DINO双流特征蒸馏}
系统采用跨模态语义（CLIP）与细粒度视觉几何（DINO）的双流特征蒸馏方案，默认启用部件级特征蒸馏以增强物体内部的结构化材质分区能力。

\subsection{CLIP 与 DINO 的特征互补机制}
CLIP 以文本-图像对比学习为核心，DINO 作为自监督视觉特征提取网络，其输出特征层对物体边界与局部纹理敏感，可抑制 CLIP 在掩码生成时的感受野外溢。
通过将两种基础模型的特征投影至蒸馏子空间（默认 32 维），网络计算渲染特征图与目标基准图在余弦相似度上的误差（Cosine Distance Loss）。针对 SAM 掩码未能覆盖的背景像素区域，系统引入\textbf{前景—背景特征对比损失}（Foreground-Background Contrast Loss）：以 SAM\cite{sam} 掩码标记的有效前景像素为界，约束预测特征在背景区域与前景区域之间保持余弦距离，抑制特征蒸馏向背景扩散。训练中所有余弦损失均通过安全包装器执行——当有效掩码区域为空时自动返回零梯度。

系统提供可配置的 DINO 归一化损失权重（dino\_norm\_loss\_weight，默认为 0.0）。特征导向的语义一致性约束（Feature-guided Semantic Consistency）采用基于 8 邻域方向（4 轴对齐 + 4 对角线）的双边滤波式空间平滑策略：仅在 CLIP 与 DINO 特征拼接向量余弦相似度超过预设阈值（默认 0.7）的相邻像素对之间，约束语义 logit 的均方误差趋于零。该机制自动在语义同质区施加平滑、在材质边界处允许突变。当特征图空间维度超过 max\_size（默认 192 像素）时，损失计算前自动通过双线性插值降采样。

\subsection{DINO 损失预热（Warmup）策略}
训练初期施加过强的 DINO 特征监督易导致高斯原语容量过度分配于抽象高维向量拟合，破坏 RGB 收敛确立的三维空间几何骨架。为此，DINO 损失权重采用线性预热函数（Scheduled DINO Loss Weight）：从起始迭代（\texttt{dino\_feature\_loss\_start\_iter}，默认 0）开始介入，初始权重由 \texttt{dino\_feature\_loss\_start\_weight}（默认 0.2）指定，在 \texttt{dino\_feature\_loss\_warmup\_iter}（默认 20,000）次迭代内线性爬坡至最终目标值 \texttt{dino\_feature\_loss\_weight}（默认 0.45）。预热完成后保持最终权重不变。该调度使不同场景可根据几何复杂度弹性调配 DINO 特征的介入节奏，在提高峰值信噪比（PSNR）的同时抑制前景-背景交界处的视觉伪影。

\section{前景解耦与材质分类框架}
在视觉蒸馏特征与材质语义标签通过双流蒸馏同步嵌入三维高斯的基础上，以下阐述面向物理仿真的材质分类框架与前景背景分割机制。

\subsection{基础材质体系映射}
系统采用 10 类材质分类框架：1 个背景类别（class 0）与 9 种物理材质类别（石材/陶瓷、玻璃、塑料、金属、木材、橡胶、沙土颗粒、流体、织物），每种材质在 \texttt{material\_config.json}（v2.0）中预定义了与 MPM 求解器类型对应的 solver\_id、杨氏模量范围、泊松比范围与密度范围。
在网络架构上，两组蒸馏特征向量分别由独立的轻量级解码器处理：视觉蒸馏特征通过 CLIP/DINO 解码器重建视觉基础模型的高维特征图，用于跨模态视觉蒸馏与训练监督；材质语义标签经由专用的语义标签解码器（Semantic Label Decoder）输出 10 通道的离散化分类 logits，将 VLM 推理得到的材质类别从二维掩码空间蒸馏至每个三维高斯原语。网络生成二维材质掩码时，通过 \texttt{semantic\_target \% 10} 及 \texttt{semantic\_target // 10} 编码剔除无效分类目标与混合模糊区域。两个解码器共享骨干网络但独立优化各自的损失函数，确保视觉语义感知与物理材质分类互不干扰。

\subsection{前景解耦与背景冻结}
完成材质分类后，需将可交互的前景物体与大规模静态背景（天空、地面、墙壁）解耦，避免背景刚度在 MPM 仿真中过度约束弹性系统。为此，系统实现了具备自适应预设的前景分割管线。阶段一（粗筛选）：从全体高斯中采样子集计算 CLIP 特征与前景文本的余弦相似度，经阈值初筛后执行得分引导的 DBSCAN\cite{dbscan} 聚类——按文本置信度（70\%）、簇尺寸（20\%）与密度（10\%）的加权综合评分选取最优聚类，构建前景粗包围盒并剔除盒外背景。阶段二（精细相似度与实例聚类）：在粗包围盒内对全量高斯计算多层级相似度并阈值过滤得到种子掩码，可选地对种子进行 DBSCAN 实例选择与包围盒扩展。阶段三（竞争性文本评分与多源证据融合）：当同时提供前景与背景文本查询时，系统对所有查询嵌入执行带温度缩放的 softmax 归一化并融合四类独立证据源——对象级 CLIP 相似度（权重 0.55）、零件级 CLIP 相似度（权重 0.20）、SAM 二维掩码反投影投票（权重 0.20）、DINOv2 特征空间 KNN 平滑余弦相似度（权重 0.05）——以增强前景与相似背景的区分能力。阶段四（KNN 平滑与连通分量过滤）：对融合得分进行阈值化后通过 FAISS\cite{faiss}-GPU 加速的 KNN 标签传播进行前景膨胀与背景清理，再利用连通分量分析提取最大空间连通簇以剔除孤立噪声碎片。阶段五（安全保护与自动回退）：系统内建多层安全机制——融合阶段前景比例过高时自动收紧融合阈值，最终前景粒子数超过上限（500,000）或前景比例超过预设上限时触发硬性拒绝，若连通分量过滤导致前景被过度剔除则自动回退至过滤前掩码。

此外，针对 CLIP 文本匹配在部分场景中前景召回不佳的问题，系统额外实现了基于 SAM 二维掩码的备选前景标记工具，通过多视角掩码投票将二维分割结果反投影至三维高斯空间，作为文本驱动方法的补充链路。经此管线，原本复杂交织的背景被有效剥离，仅保留真正参与交互的前景主体进入后续的 MPM 仿真阶段。

\subsection{长尾分布及边界加权的约束优化}
在进行真实场景材质归类时，稀有材质类别仅占据极少的视度像素，形成长尾分布。系统在损失评估中引入区域反频率权重，对稀有材质进行自适应误差放大，以 $\gamma=0.3$ 的类别平衡指数对交叉熵损失加权。语义标签解码器中引入独立于视觉蒸馏的\textbf{语义标签特征库}，使语义分类损失的梯度仅回传至语义标签专用特征，不污染 CLIP/DINO 的视觉蒸馏特征空间。为进一步确保三维语义一致性，系统引入\textbf{逐高斯语义一致性损失}：利用光栅化器输出的像素-高斯索引，将二维语义标签反投影至每个高斯原语进行投票监督，约束各高斯在三维空间中保持统一的材质归属。语义损失的时延调度为：像素级交叉熵从训练起始接入，语义特征更新在 50,000 次迭代后关闭以保证视觉特征充分收敛，逐高斯约束延迟至 25,000 次迭代并以 5,000 次线性启动。
深度混叠易导致物质边界处的物理参数重叠，算法增加了类别边界感知加权机制：对深度陡变或特征不连续处标记为 ignored pixels 的不可靠像素，通过局部特征余弦平滑约束两侧空间特征的纯净性。为防止复杂场景训练中的显存溢出，此外，本文系统引入硬性的高斯点密度上限控制以避免显存爆炸，高斯例子数量达到阈值时屏蔽致密化操作。

\section{本章小结}
本章阐明了从二维语义特征到三维物理材质场的蒸馏解耦与前景隔离方法。在特征预提取阶段，以分割为基础，完成对象级与零件级 CLIP 特征聚合及 DINOv2 空间结构特征提取，并通过掩码过滤机制确保监督信号的一致性。在蒸馏阶段，将 CLIP 与 DINO 特征投影至 32 维蒸馏空间并施加余弦相似度损失与前景背景对比损失，驱动高斯粒子在保持几何外观的同时对齐视觉蒸馏特征空间；参数化的 DINO 预热机制确保几何骨架在训练初期优先巩固。在材质分类与前景分割阶段，通过独立的语义标签特征库与语义标签解码器实现材质分类，配合前景分割管线实现前景主体与静态背景的隔离，并通过逐高斯语义一致性损失、特征引导的 8 邻域平滑约束等优化，处理了多任务特征冲突与显存控制等工程问题。本章构建的语义-材质双重表征与前景分割机制，为后续 MPM 多材质仿真提供了边界分明、属性完备三维场景。
